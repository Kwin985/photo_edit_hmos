# ArtsPhoto 差异化清单（对标 AirPhoto）

> 本清单是 1.0.0 上架、1.0.1 审核中之后的**后续版本（1.0.2 起）**路线图。
> SWOT 依据：`docs/` 上一轮《AirPhoto SWOT 分析》。
> 对标对象：**AirPhoto（纯血鸿蒙版）** `com.airphoto.app`，v1.7.0，4.6 分 / 8,282 下载，2026-08-11 上架，2026-10-27 更新，开发者陈彦霖，97.7 MB，target SDK 26 / min SDK 23，设备手机·折叠屏·PC。
> 数据来源：`fangzhou.club/apps/com.airphoto.app`（鸿蒙应用市场公开数据镜像）；华为应用市场原始页为 JS 渲染未取到正文。
> 核实边界：AirPhoto 商城介绍只到高层口径（矢量绘图/像素修图/图层管理/色彩校正/智能抠图/多端协同），**图层样式/蒙版/PSD/滤镜/自由变换深度、确切 requestPermissions、技术栈、测试工程均未证实**。
> 闭合进展（2026-11-19，见 §1.1）：V1 部分闭合（图层(L) 入口已证），V2–V5 未闭合（需装应用）；截图另证 `图层(L)/滤镜(R)/图像(I)/颜色(C)/工具(T)` 菜单入口、`模式/不透明度` 面板、撤消/重做/复制可见、文字工具、平移/滚轮/分块渲染。

## 2. A 类：对标补齐落后功能

> 本项目相对 AirPhoto 已核实的空白能力。原则：**补齐不得破坏 B1 纯离线隐私定位**（这是本项目第一优势，任何新功能不得引入网络权限）。

### A1 矢量绘图能力（钢笔路径 + 锚点调节） — P0 / 高工作量 / 目标 1.2.0

- **现状**：本项目无矢量（ABI 入口 `native/ohos-bridge/src/lib.rs:1001+` 无 vector 项，已证）。
- **AirPhoto**：有钢笔路径、锚点调节（商城介绍已证）。
- **差距**：完全空白，单项最大缺口。
- **具体动作（分阶段）**：
  1. 矢量数据模型：`Path` / `Anchor` / `Handle`（控制柄）+ Rust 核心贝塞尔栅格化（复用 `native/crates/raster`、`geom`）。
  2. 钢笔工具 UI：点击落锚点、拖拽控制柄、锚点调节（增/删/转换角点与平滑点）。
  3. 矢量图层类型：与位图图层并存，参与混合模式/不透明度/自由变换。
  4. 路径转选区、描边/填充。
- **验收**：钢笔工具可绘制闭合/开放路径；锚点拖拽控制柄调节；矢量图层参与混合与变换；逐位等价测试覆盖。
- **对应 SWOT**：W1。
- **约束**：单人开发最大单项投入，建议 1.2.0 主线；1.1.0 先做 B2/C1 快速见效。

### A2 AI 智能抠图 — P1 / 中高工作量 / 目标 1.2.0–1.3.0

- **现状**：仅魔棒选区（阈值容差），无 AI（ABI `pc_select` 无智能抠图）。
- **AirPhoto**：有"智能抠图"（商城介绍已证）。
- **差距**：无 AI 抠图。
- **具体动作**：
  1. 方案选型：本地轻量模型（U2-Net/ModNet 类端侧部署）vs 传统算法（GrabCut 类）。
  2. **纯离线硬约束**：模型必须本地打包，不联网、不上传——守住 B1。不得为补此功能引入网络权限。
  3. 集成：选区工具新增"智能抠图"模式，一键抠主体，边缘输出为选区可再编辑。
- **验收**：一键抠出人像/主体；纯离线无网络（`requestPermissions` 回归为空）；体积增量可控。
- **对应 SWOT**：W2。
- **决策点 D2**：本地模型 vs 传统算法——影响体积与离线定位，需用户定。

### A3 多端协同 / 文件流转 — P1 / 中工作量 / 目标 1.3.0

- **现状**：无跨设备协同（有 insightIntent 2 意图 + 服务卡片 1 张，但非跨设备）。
- **AirPhoto**：有"多端协同与文件流转"（商城介绍已证）。
- **差距**：无跨设备。
- **具体动作**：
  1. HarmonyOS 分布式能力：`distributedData` / `distributedFile` / 跨设备接续（continuation）。
  2. 阶段1：接续——跨设备接续编辑同一文档。
  3. 阶段2：distributedFile 文件流转。
- **验收**：跨设备接续编辑、文件流转可用。
- **对应 SWOT**：W3。
- **决策点 D3（张力最大）**：多端协同需设备发现/通信，与 B1"纯离线零网络"存在张力。**必须限定为近场设备间（局域网/近场，不经公网、不上传云端）**，否则破坏第一优势。是否做、做到什么程度，需用户定。

## 3. B 类：加强优势功能

> 本项目已核实的相对 AirPhoto 优势。原则：**强化不新建为主，守住并放大已证实的护城河。**

### B1 纯离线隐私强化 — P0 / 低工作量 / 目标 1.0.2 + 持续

- **现状**：`module.json5` 无 `requestPermissions`，纯离线（已核实）。
- **优势**：AirPhoto"多端协同"推断联网（V4 闭合后定论），本项目结构性独占。
- **具体动作**：
  1. 商城首屏文案强化"零网络权限、纯离线、不上传"（见 C1）。
  2. App 内隐私状态可视化：设置页显示"网络权限：无 / 数据：仅本地内存"。
  3. 提审数据安全勾选"不收集个人信息"保持。
  4. **守住源头**：任何新功能（A2/A3）不得引入网络权限——本清单所有项的硬约束。
- **验收**：商城文案 + App 内隐私状态 + `module.json5` 无 `requestPermissions` 回归 PASS。
- **对应 SWOT**：S1 / O1。

### B2 图层专业纵深强化 — P0/P1 / 中工作量 / 目标 1.1.0

- **现状**：7 种图层样式 + 图层蒙版（密度/羽化/链接）+ 自由变换实时预览 + 历史记录跳转 + PSD/PSB 打开（全部已核实）。
- **优势**：AirPhoto 深度未证实（V1–V3 闭合后定论）——若 AirPhoto 无则本项目独占。
- **具体动作**：
  1. **PSD/PSB 导出**（当前只打开、不导出；导出仅 PNG/JPEG/WebP）——可落地的具体纵深点，直接补格式闭环。
  2. 图层样式扩展（叠加选项、描边更多参数）。
  3. 蒙版密度/羽化/链接稳定性回归。
  4. 条件分支：V1–V3 证实 AirPhoto 也有 → 转"加深差异化"；AirPhoto 无 → 转"加大宣传"。
- **验收**：PSD/PSB 导出可用，回读逐位一致；图层样式/蒙版回归 PASS。
- **对应 SWOT**：S3 / O2。
- **决策点 D4**：V1–V3 闭合后定"加深"还是"补齐"。

### B3 体积优势保持 — P1 / 低工作量 / 目标 1.0.2 起持续

- **现状**：HAP 60–66 MB（已核实）。
- **优势**：AirPhoto 97.7 MB，本项目更轻（已核实）。
- **具体动作**：
  1. 建立体积回归门禁：每次出包记录 HAP 体积，超阈值告警。
  2. 优化 Rust `.so`（strip / lto）、CJK 字体子集化。
  3. 目标：保持 < 70 MB（远低于 AirPhoto 97.7 MB）。
- **验收**：出包体积门禁 PASS。
- **对应 SWOT**：S2 / O3。
- **约束**：A1 矢量/A2 抠图会增体积，必须用本门禁守住体积优势。

### B4 工程质量维持 — P1 / 低工作量 / 目标 持续

- **现状**：76 Rust + 88 hypium + 真机 arm64 全量回归 PASS + PERF 埋点（已核实）。
- **优势**：AirPhoto 测试未证实。
- **具体动作**：
  1. 每版本回归 88 hypium + 真机 arm64 回归。
  2. C1（设备并行重采样无收益）/ C4（GPU 缺位）——平台限制 NOT_VERIFIED，SDK 26 若提供新能力可重测。
  3. clippy deny 零新增。
- **验收**：回归全 PASS。
- **对应 SWOT**：S5。

### B5 中文字体维护 — P2 / 低工作量 / 目标 持续

- **现状**：rawfile 内置 NotoSansCJKsc.otf + `initTextFont` 注册（已核实）。
- **优势**：真机中文不缺字。
- **具体动作**：维持 rawfile 字体 + 注册；新设备/新 SDK 回归。
- **验收**：真机中文纹理无缺字。
- **对应 SWOT**：S6。

### B6 鸿蒙生态特性扩展 — P1 / 中工作量 / 目标 1.1.0–1.2.0

- **现状**：服务卡片 1 张 + insightIntent 2 意图（已核实）。
- **优势**：AirPhoto 是否落地未证实（V5 闭合后定论）。
- **具体动作**：
  1. 服务卡片 1→多（快速新建、最近文档卡片）。
  2. insightIntent 2→更多意图（语音"打开最近编辑"等）。
  3. 跨设备流转与 A3 协同，但本条侧重生态特性表达。
- **验收**：卡片/意图真机可用（走 `uitest` 链路）。
- **对应 SWOT**：O4。
