# ArtsPhoto 演进规划（SWOT 驱动版）

> 制定日期：2026-11-19
> 上游依据：`docs/AirPhoto_SWOT_真机对比.md`（真机证据版 SWOT）
> 版本基线：1.0.0 已上架 / **1.0.1 审核中（内容锁定，不改）** → 本规划从 **1.0.2** 起
> 资源口径：**单人开发**，不可并行推进 A1/A2/A3 三条大线；"高"=数周~数月，"中"=数天~数周，"低"=数小时~数天

---

## 一、战略重定位（规划的总纲）

SWOT 分析带来两条硬修正，直接决定演进方向：

| 修正 | 旧认知 | 新认知 | 对规划的影响 |
|---|---|---|---|
| V4 闭合 | 竞品"多端协同"推断联网，本作"不联网"独占 | 竞品无 INTERNET 权限、无云同步；本作 0 权限 vs 竞品 2 项本地权限 | 定位从"唯一不联网"改为"**零权限**"；A3 协同优先级下调 |
| V5 闭合 | 卡片/意图优势待核实 | 竞品无卡片无意图，本作**独占生态位** | 生态卡位升为主线，1.1.0 优先兑现 |
| T1 新威胁 | 图层纵深可能独占 | 竞品疑似 GIMP 移植，纵深大概率更强 | 放弃"功能清单对标"，改打**触屏体验 + 轻量 + 隐私 + 生态** |

**一句话定位：**

> **零权限的鸿蒙原生触屏图层编辑器**——不与 GIMP 系竞品拼功能数量，拼"同样专业、但更安全、更轻、更像鸿蒙"。

**四条战略主线（按优先级）：**

1. **守零权限**（S1）：所有演进项的硬约束，任何新功能不得引入网络权限。
2. **抢生态卡位**（S3/O2）：服务卡片 + 意图做深做透，形成竞品短期无法对齐的鸿蒙原生体验。
3. **打触屏体验差**（S7/O4）：把"专业图层编辑"做成手机上真正好用的形态，而非桌面菜单的搬运。
4. **保持轻量与稳定**（S2/S5）：体积门禁 < 70 MB、回归全 PASS 是整个演进的质量底座。

## 二、演进红线（不可突破）

| 编号 | 红线 | 检查方式 |
|---|---|---|
| R1 | 不得引入 `requestPermissions`（尤其 INTERNET）；A2 本地模型、A3 近场协同须回归验证 | `module.json5` 无 `requestPermissions` + 发布包自检 |
| R2 | 发布包体积 < 70 MB（竞品 97.7 MB） | 每次出包记录 HAP/APP 体积，超阈值告警 |
| R3 | 回归不退化：76 Rust + 88 hypium + 真机 arm64 全 PASS | 每版本全量回归 |
| R4 | 1.0.1 审核中内容锁定，不改；每版本 versionCode 严格递增 | 1000003 起 |
| R5 | 推断项（竞品矢量/抠图/PSD 导出/GIMP 血统）未闭合前不写入对外宣传 | 宣传文案评审对照本报告证据等级 |
| R6 | 单人开发节奏，A1/A2/A3 不并行 | 版本主线单一 |

## 五、决策门（需用户拍板，阻塞对应阶段）

| 编号 | 决策点 | 阻塞 | 建议 | 依据 |
|---|---|---|---|---|
| D1 | 是否投入 A1 矢量（最大单项，数周~数月） | 阶段 3 主线 | **建议做但放 1.2.0**，单人开发不与其他大线并行；若资源紧张，走 3B 触屏纵深替代主线 | W1 缺口大但非独占竞争的关键 |
| D2 | A2 抠图：本地模型 vs 传统算法 | 3C 启动 | **建议传统算法起步**（体积小、守住零权限与体积红线），本地模型待验证 | R1/R2 硬约束 |
| D3 | A3 协同：做不做、做到什么程度 | 阶段 4 | **建议降级为近场文件流转**，明确不经公网；若 D2/体积承压可延后 | 竞品无公网，紧迫性下降 |
| D4 | B2 纵深"加深"还是"补齐" | 2.4 力度 | **已收敛：按"竞品大概率具备"做闭环补齐**，不作为独占宣传 | T1 高置信推断 |

> **决策已拍板（2026-11-20）**：D1 = **投入矢量**（A1 主线）；D2 = **传统算法起步**（GrabCut/Select Subject，纯离线）；D3 = **近场不经公网**（HarmonyOS 系统分享面板）。
> 落地版本：D1/D2 随 1.2.0 交付（矢量路径转选区 ABI + 智能抠图 ABI/UI）；D3 随 1.2.0 一并交付（近场分享，经 ShareKit 系统分享面板，无网络权限）。
> 说明：SDK 的 openharmony 部分无 ShareKit，需 hms SDK（`@kit.ShareKit`）；已确认可用并构建通过。

## 九、与既有清单的关系

本规划**取代** `docs/DIFFERENTIATION_CHECKLIST.md` §5 的版本节奏主线（B/A/C 项编号保留，便于追溯），差异如下：

| 项 | 原清单 | 本规划 | 原因 |
|---|---|---|---|
| B1 隐私 | "独占不联网"宣传 | "零权限"定位纠偏 | V4 闭合 |
| B6 生态 | 1.1.0~1.2.0 扩展 | **1.1.0 提前并升为 P0 主线** | V5 闭合，独占窗口 |
| A3 协同 | P1 / 1.3.0 | P1→降级近场 / 1.3.0 | V4 闭合，紧迫性下降 |
| D4 | 未定论 | 收敛为"闭环补齐" | T1 高置信推断 |
| 触屏体验 | 无独立项 | **新增 2.3 触屏交互专项 P0** | S7/O4 差异化主线 |
