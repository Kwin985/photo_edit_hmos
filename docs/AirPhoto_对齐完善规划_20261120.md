## 二、AirPhoto 差距分析（A1 D2 补后更新）

> 原 SWOT 的 W1（矢量）、W2（抠图）已随 1.0.2 补齐。以下为**更新后**的差距清单。
> 证据等级：**[已证]** 真机/源码/构建直接观测；**[推断]** 合理推断；**[未证]** 商城口径无二进制/运行证据。

| # | 差距 | AirPhoto 侧证据 | 本项目现状 | 类别 | 对应原 SWOT |

### 2.3 战略结论

- **不能赢的维度**：功能清单总数（竞品疑似 GIMP 移植，纵深大概率更强）——不拼数量。
- **可守的护城河**：零权限（L1）+ 轻量（L2）+ 生态独占（L3）+ 触屏体验（L7）——这四项竞品短期无法对齐或不愿对齐。
- **最高优先级动作**：补 G1（PSD 导出）+ G2（复制可见）补格式/编辑闭环；做深 G3/G4 放大护城河；G5 降级近场守零权限；G6/G7 视资源。

## 六、不涉及企业开发者功能界定

> 用户明确："先不涉及企业开发者的功能"。本规划所有功能项均限制在个人开发者可用的 API 范围内。

| 企业开发者功能（本规划不做） | 替代（个人开发者可做） |
|---|---|
| 系统级权限（MDM、设备管理、受限 API） | 零权限路线（R1），不申请任何权限 |
| 企业分发 / 企业签名 | AGC 个人开发者上架 |
| 企业级分布式数据（需企业签名的 distributed 高级能力） | ShareKit 系统分享面板（个人开发者可用）做近场流转 |
| 企业级设备发现/通信 | 系统分享面板 + 近场文件流转（不经公网） |

**本规划所有功能项均使用个人开发者可用的标准 API**：ShareKit、服务卡片、insightIntent、NAPI、Rust core、标准 ArkTS/ArkUI。无需企业签名。

```
BIAS_ADD:      params=[],        inputs=[20, 3],     outputs=[21]  bias_out = matmul_out + bias      (shape [1,n,1,3])
MAXIMUM:       params=[],        inputs=[21, 14],    outputs=[22]  clamped_lo = max(bias_out, 0)     (shape [1,n,1,3])
MINIMUM:       params=[],        inputs=[22, 15],    outputs=[23]  clipped = min(clamped_lo, 1)      (shape [1,n,1,3])
CONCAT:        params=[13],      inputs=[23, 16],    outputs=[24]  result = concat([clipped, alpha], axis=3)  (shape [1,n,1,4])
SELECT:        params=[],        inputs=[18, 24, 0], outputs=[1]   out = where(mask_b, result, src)  (shape [1,n,1,4])
```
常量：`weights=[3,3]`（非 monochrome: [m00,m01,m02,m10,m11,m12,m20,m21,m22]；monochrome: [m00,m01,m02, m00,m01,m02, m00,m01,m02]）、`bias=[3]`（非 monochrome: [m03,m13,m23]；monochrome: [m03,m03,m03]）、`tx=[0]`、`ty=[1]`、`activationType=[0]`、`axis=[3]`、`rgb_begin=[0]`、`rgb_size=[3]`、`alpha_begin=[3]`、`alpha_size=[1]`、`bshape=[1,n,1,4]`、`concat_axis=[3]`、`zero=[0.0]`、`one=[1.0]`。

**语义等价**：`out[i] = (matrix[i][0]*c[0] + matrix[i][1]*c[1] + matrix[i][2]*c[2] + matrix[i][3]).clamp(0.0, 1.0)` for i in 0..3，alpha preserved。Where alpha <= 0 → original pixel（skip）。与标量 `channel_mixer` 逐位等价。clamp 用 MAXIMUM(0) + MINIMUM(1) 实现（CLIP 要求空 shape 标量张量，风险较高，改用 MAXIMUM+MINIMUM 更安全）。MATMUL 用 TransposeY=true 实现 `rgb @ weights^T`。CONCAT 将 [1,n,1,3]（clipped RGB）与 [1,n,1,1]（alpha）沿 axis=3 拼接为 [1,n,1,4]。monochrome 通过设置 weights 行1/行2=行0、bias=[m03,m03,m03] 实现，不改计算图。

**Rust 2024 edition 适配**：同 §12.3-sexies（`unsafe extern "C"`、`unsafe { }` 块、`let mut`）。

**链接验证**：同 §12.3-sexies（`#[link(name = "neural_network_runtime")]` + `#[link(name = "neural_network_core")]` aarch64 `cargo build` 成功链接）。

**性能定位**：NPU 真机加速比待验（设备离线）。channel_mixer 的 NPU 计算图含 10 操作（2×SLICE + GREATER + BROADCAST_TO + MATMUL + BIAS_ADD + MAXIMUM + MINIMUM + CONCAT + SELECT），是当前最复杂的 NPU 计算图；NNR 推理有模型构建/编译/执行开销，对小批量像素可能不如 SIMD；对大批量像素（整层调整）NPU 并行优势可能显现。需设备连接后 bench 验证。

#### 12.3-duodecim NPU 加速路径：`mat3_mul_rgba8` NNR 推理（2026-11-22）
