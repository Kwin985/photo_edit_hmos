## 1. 平台规范（AGC 实际要求）

| 项 | 要求 |
|---|---|
| 数量 | **3 ~ 10 张** |
| 手机 | 竖屏，建议 **1080×1920**（9:16）；真机 1224×2700 可先拍后缩放 |
| 平板 / 2in1 | 横屏 **1920×1080**（16:9），最低 1920×1080 |
| 格式 | PNG / JPG / JPEG，单张 ≤ **5 MB** |
| 内容 | 必须是真实应用界面；**不得含第三方品牌标识、其他应用界面、个人信息、二维码** |

**进度**：横屏 **4 / 3**、竖屏 **3 / 3**，均已达到 3~10 张要求（7 张，均 ≤ 5 MB）。

**取景方法（已实测）**：MateBook Pro 模拟器整屏 3120×2080，应用最大化后取 `y=0..1755`，再 LANCZOS 缩放到 1920×1080。该区间能完整容纳顶栏、缩放条、画布图像与右侧面板上半，比例精确 16:9。

**已知问题（已修复，勿回退）**：
- 旧 `sample.jpg` 是一张 Photoshop 界面截图，含 Adobe 品牌，**不可用于截图**；现已替换为自绘风景图（`scripts/make-sample.py`）。
- 画布曾因 `createPixelMap` 未指定 `srcPixelFormat` 导致 R/B 通道交换；已在 5 处 PixelMap 初始化中补 `srcPixelFormat: RGBA_8888`，截图颜色与原图一致。
- 2in1 默认窗口化会露出壁纸与任务栏；已在 `EntryAbility.maximizeIf2in1` 中最大化。

## 4. 拍摄命令（模板）

```bash
HDC="D:/Program Files/Huawei/DevEco Studio/sdk/default/openharmony/toolchains/hdc.exe"
TARGET="127.0.0.1:5555"   # 或真机 4GJBB25213005674

# 冷启动
MSYS_NO_PATHCONV=1 "$HDC" -t "$TARGET" shell "aa force-stop com.kwin.photocraft"
MSYS_NO_PATHCONV=1 "$HDC" -t "$TARGET" shell "aa start -a EntryAbility -b com.kwin.photocraft"
sleep 4

# 截图并取回
MSYS_NO_PATHCONV=1 "$HDC" -t "$TARGET" shell "snapshot_display -f /data/local/tmp/shot.jpeg"
MSYS_NO_PATHCONV=1 "$HDC" -t "$TARGET" file recv /data/local/tmp/shot.jpeg ./verify-artifacts/shot.jpeg
```

PC 裁切（3120×2080 → 1920×1080）：

```python
from PIL import Image
src = Image.open('verify-artifacts/shot.jpeg')
src.crop((0, 0, 3120, 1755)).resize((1920, 1080), Image.LANCZOS).save(
    'docs/launch/screenshots/artsphoto_pc_x_1920x1080.jpg', quality=92, optimize=True)
```

手机裁切（1224×2700 → 1080×1920，保持 9:16）：

```python
from PIL import Image
src = Image.open('verify-artifacts/shot.jpeg')
src.crop((0, 200, 1224, 2376)).resize((1080, 1920), Image.LANCZOS).save(
    'docs/launch/screenshots/artsphoto_phone_x_1080x1920.jpg', quality=92, optimize=True)
```

## 5. 出图前检查

- [ ] 画面中无 Photoshop / Adobe / 其他应用界面或图标。
- [ ] 无壁纸、任务栏、系统 Dock 露出（2in1 必须最大化）。
- [ ] 无文件名、路径、账号、时间等个人信息（标题栏的 `sample.jpg` 可接受）。
- [ ] 画布颜色正常（天空蓝紫、太阳暖黄），不是 R/B 交换的偏红色。
- [ ] 单张 ≤ 5 MB，比例符合对应设备 tab。
- [ ] AGC 上传的图标与桌面安装图标一致（见 `上架指引-个人开发者.md` §图标一致性）。
