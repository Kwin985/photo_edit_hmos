# ArtsPhoto 1.0.2 新版本特性

> 应用市场「新版本特性」填写文案，可直接复制。

1. **滤镜能力全面扩展**：新增 61 种引擎滤镜，按模糊锐化、杂色修复、扭曲变形、像素风格、艺术渲染等分组；内置 47 种画廊预设，支持两级分类与参数调节。
2. **专业调色升级**：新增色阶与曲线调整，支持总通道及 RGB 独立通道，调整实时预览并可撤销。
3. **绘图与抠图更完善**：钢笔工具支持贝塞尔路径、栅格化与路径转选区；智能抠图生成非破坏性蒙版，背景透明化可随时撤销。
4. **格式与导出优化**：支持 HEIC/HEIF 照片打开，完善 PSD/PSB、PNG、JPEG、WebP、TIFF 等格式流程；WebP 导出质量调节生效，修复导出文件描述符泄漏。
5. **大图处理更稳定**：打开、导出、滤镜、抠图及复制可见等重任务异步执行；补齐高斯模糊带内进度，支持在途取消，取消后不修改文档、像素与历史记录。
6. **隐私与体验**：保持零权限、纯离线、无广告、无订阅；优化滤镜异步竞态、撤销后的数据刷新及手机、平板、2in1 设备适配。
