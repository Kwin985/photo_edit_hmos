# ArtsPhoto 隐私政策

更新日期：2026-11-12　生效日期：2026-11-12

ArtsPhoto（以下简称“本应用”）是一款运行在 HarmonyOS 设备上的本地图像编辑工具。我们深知个人信息对您的重要性，并会依照《中华人民共和国个人信息保护法》等法律法规处理您的信息。本政策说明本应用如何处理与您有关的信息。

## 一、适用范围

本政策适用于 ArtsPhoto 应用本身。本应用不包含账号体系、广告、统计分析或任何在线服务，也不链接到第三方网站。

## 二、我们如何收集和使用信息

1. 本应用不收集、不上传任何个人信息，不采集设备标识符（IMEI、OAID、SN 等）、位置、通讯录、通话记录、短信、剪贴板或应用列表。
2. 您通过系统文件选择器主动选择的图片文件，仅在您的设备本地内存中被读取、编辑与导出。文件内容不会发送到任何服务器，本应用也未申请网络权限。
3. 本应用没有广告 SDK、统计 SDK、推送 SDK、崩溃上报 SDK 或其他第三方 SDK。

## 三、本地存储的信息

为记住您的使用偏好，本应用在设备本地保存以下设置：标尺是否显示、网格间距、参考线是否显示、打开图片时的默认缩放方式。上述数据仅保存在本机应用沙箱内，不会上传；卸载本应用或清除应用数据后即被删除。

## 四、系统权限与文件访问

本应用不申请任何系统敏感权限。打开与保存文件均通过 HarmonyOS 系统文件选择器完成，本应用只能访问您在该选择器中明确选择的文件，无法访问其他文件或相册。

## 五、信息的共享、转让与公开披露

由于本应用不收集个人信息，因此不存在向第三方共享、转让或公开披露个人信息的情形，也不存在跨境传输。

## 六、近场文件流转
1. 本应用通过 HarmonyOS 系统分享面板提供近场文件流转能力，用户可将导出的图片分享至附近设备或其他应用；传输由系统完成，本应用不自行建立任何网络连接。
2. 近场文件流转**不经公网**：所有文件在设备间的传输均在本地网络或设备间直接进行，不经过任何公共服务器或云端存储。
3. 本应用不上传、不存储、不转发任何用户文件到公网服务器。用户通过系统分享发送的文件，由接收端自行在本地处理与存储。
4. 若用户选择分享文件至他应用或云服务，本应用不拦截也不会记录相关行为，该行为由系统和用户自行决定。
5. 本应用不提供任何公网备份、云同步或跨境传输功能，所有文件均保留在用户的设备本地。

## 六、信息的存储地点与期限

偏好设置存储在您的设备本地，保存期限为您使用本应用期间；卸载应用或清除应用数据后即删除。您选择的图片文件由您自行保管，本应用不保留副本。

## 七、信息安全

本应用在本地处理图片与设置，不经过网络传输。请妥善保管您的设备与文件；因设备丢失、系统被破解或您主动分享文件造成的信息泄露，不属于本应用可控范围。

## 八、未成年人保护

本应用为通用图像编辑工具，不面向未成年人单独收集信息。未成年人应在监护人指导下使用本应用。若监护人发现未成年人向我们提供了信息，可通过本政策末尾的方式联系我们。

## 九、您的权利

1. 您可以在“关于 ArtsPhoto”页面查看本政策与用户协议。
2. 首次启动时的隐私声明同意由 HarmonyOS 系统隐私托管服务统一记录与管理；如需重新阅读本政策，您可以在“关于 ArtsPhoto”页面随时查看。
3. 您可以随时卸载本应用或清除应用数据，以删除本地保存的全部设置。
4. 由于本应用不收集个人信息，不存在需要查阅、复制、更正或转移的个人信息。

## 十、政策更新

若本应用的功能或信息处理方式发生变化，我们会更新本政策，并在应用内以显著方式提示您重新阅读与同意。未经您同意，我们不会削减您依据本政策享有的权利。
